# Desarrollo Web en Entorno Cliente (DWEC)

Repositorio destinado a la publicación de ejercicios, actividades y proyectos de la asignatura **Desarrollo Web en Entorno Cliente**.

## Tecnologías Utilizadas
- Lenguaje Principal: JavaScript (ES6+)
- Estructura y Estilos: HTML5 / CSS3
- Generador de Sitio Estático: Jekyll (Tema Cayman)
- Control de Versiones y Despliegue: Git, GitHub & GitHub Pages
